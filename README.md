# VulnLab — Web Application Security Laboratory

VulnLab est un laboratoire pédagogique de sécurité applicative exclusivement local.
Il comparera une application fictive de tickets volontairement vulnérable et sa version corrigée.
Le service vulnérable ne doit jamais être publié ni déployé ; seules des données fictives sont autorisées.

Ce commit amorce le dépôt avec ce README et les exclusions Git. Il ne fournit aucune application exécutable.
Le socle documentaire, Python et Docker sera proposé sur une branche dédiée, via une pull request pour revue.
